# Project 2: Exploratory Data Analysis with Python

## Project Overview

This is the second project completed as part of the **DecodeLabs Data Analytics Internship**.

The project focuses on performing Exploratory Data Analysis (EDA) on a cleaned sales dataset using Python. The goal is to understand sales patterns, identify trends, analyze customer behavior, and extract meaningful business insights from the data.

---

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- GitHub

---

## Dataset

The dataset contains **1,200 sales records** with **14 columns**, including:

- Order ID
- Date
- Customer ID
- Product
- Quantity
- Unit Price
- Shipping Address
- Payment Method
- Order Status
- Tracking Number
- Items in Cart
- Coupon Code
- Referral Source
- Total Price

The analysis was performed using the cleaned dataset generated from **Project 1 – Data Cleaning with Python**.

---

## Tasks Performed

### 1. Data Exploration

- Inspected the dataset structure.
- Reviewed data types and descriptive statistics.
- Checked the number of rows and columns.
- Verified missing values and duplicate records.

### 2. Product Analysis

- Analyzed the number of orders by product.
- Identified the top 10 products by order volume.
- Analyzed revenue generated by each product.
- Identified the top 10 products by revenue.

### 3. Revenue Analysis

- Calculated total revenue.
- Calculated average order value.
- Analyzed revenue by product.
- Identified the highest-revenue products.

### 4. Time Analysis

- Analyzed the number of orders by month.
- Analyzed monthly revenue.
- Identified changes in sales performance over time.

### 5. Payment Method Analysis

- Analyzed the number of orders by payment method.
- Compared revenue generated by different payment methods.

### 6. Order Status Analysis

- Analyzed the distribution of order statuses.
- Compared revenue by order status.
- Calculated the cancellation rate.

### 7. Coupon Analysis

- Analyzed coupon usage.
- Compared orders using coupons with orders without coupons.
- Analyzed revenue by coupon code.

### 8. Referral Source Analysis

- Analyzed the number of orders by referral source.
- Compared revenue generated by referral sources.
- Calculated the average order value by referral source.

### 9. Correlation Analysis

- Analyzed relationships between numerical variables.
- Created a correlation matrix.
- Examined the relationship between Quantity and TotalPrice.
- Examined the relationship between UnitPrice and TotalPrice.

---

## Key Business Insights

- The dataset contains **1,200 orders**.
- Total revenue generated is **1,264,761.96**.
- The average order value is approximately **1,053.97**.
- **Printer** is the top-selling product by order volume, with **181 orders**.
- **Online** is the most commonly used payment method, with **258 orders**.
- **Instagram** is the most common referral source, with **259 orders**.
- **Cancelled** is the most common order status, with **250 orders**.
- The cancellation rate is approximately **20.83%**.
- The relatively high cancellation rate represents an area that may require further investigation to improve order completion.

---

## Results

The EDA process provided a clearer understanding of the sales dataset and revealed important patterns related to products, revenue, payment methods, order statuses, coupons, and referral sources.

The analysis also helped identify key business areas that could be investigated further, particularly the relatively high order cancellation rate and the performance of different referral sources.
